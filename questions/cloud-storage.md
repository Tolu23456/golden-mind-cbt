# Cloud Storage

## What is the cloud?

- [ ] A storage space inside the screen
- [x] Storage on computers reached through the internet
- [ ] A type of printer

> "The cloud" is other people's servers, managed for you.

## What does syncing do?

- [ ] Deletes older files
- [x] Keeps the same folder updated on more than one device
- [ ] Compresses every photo
- [ ] Shares a file with everyone

> A change on one device appears on the others once they are online.

## Which permission lets someone read a file but not change it?

- [ ] Editor
- [ ] Owner
- [x] Viewer
- [ ] Commenter who can also edit

> Give the lowest permission that does the job. Viewer is read-only.

## Why should you empty the trash after deleting large files?

- [ ] It changes the file type
- [x] The space is only freed when the trash is emptied
- [ ] It shares the files
- [ ] It makes the internet faster

> Deleted files often sit in the trash until you empty it.

## What does marking a file for offline use do?

- [ ] Uploads it twice
- [x] Keeps a copy on the device so it opens without internet
- [ ] Makes it public
- [ ] Changes it to a PDF

> Download important files before a journey or a power cut.

## What is the "two copies in two places" rule?

- [ ] Keep two names for one file
- [x] Keep at least two copies of important work in different places
- [ ] Share a file with two people
- [ ] Use two passwords

> One copy on your device and one in the cloud protects against loss.
