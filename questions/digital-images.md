# Photos & Screenshots

## Which format is usually best for a photograph?

- [ ] SVG
- [x] JPG
- [ ] TXT
- [ ] HTML

> JPG compresses photos well, at the cost of a little detail.

## Which format is best for a screenshot containing text?

- [ ] JPG
- [x] PNG
- [ ] MP3
- [ ] ZIP

> PNG keeps sharp edges and text crisp.

## What is an SVG?

- [ ] A video format
- [x] An image made of shapes and maths that stays sharp at any size
- [ ] A type of spreadsheet
- [ ] A password manager

> SVG is ideal for icons, logos and diagrams.

## What happens when you enlarge a small image too much?

- [ ] It becomes sharper
- [x] It becomes blurry or blocky
- [ ] It turns into a video
- [ ] It loses its colour permanently

> Enlarging invents pixels. Always start with the largest original.

## What does cropping an image do?

- [ ] Changes its file type
- [x] Removes part of the edges
- [ ] Makes it darker
- [ ] Adds alt text

> Cropping reframes the picture by cutting away the outside.

## Why check the background before posting a photo?

- [ ] To make it brighter
- [x] It may reveal private details or people who did not agree
- [ ] To change the format
- [ ] To add a filter

> House numbers, badges and bank cards can be visible in the background.

## What is good alt text for a chart?

- [ ] "image"
- [ ] "chart1.png"
- [x] "Chart showing pass rates rising from 60% to 87%"
- [ ] "A nice picture"

> Describe the meaning, not the file name.
