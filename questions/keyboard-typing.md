# Keyboard & Typing

## Which keys make up the home row on the left hand?
- [ ] Q W E R
- [x] A S D F
- [ ] Z X C V
- [ ] 1 2 3 4
> A S D F are where the left fingers rest.

## Which key deletes the letter BEFORE the cursor?
- [ ] Delete
- [x] Backspace
- [ ] Enter
- [ ] Tab
> Backspace deletes backwards.

## Which key starts a new line?
- [x] Enter
- [ ] Shift
- [ ] Esc
- [ ] Ctrl
> Press Enter to move to the next line.

## Which key do you hold to type a capital letter?
- [ ] Ctrl
- [ ] Alt
- [x] Shift
- [ ] Tab
> Hold Shift and press a letter.

## What does Caps Lock do?
- [ ] Deletes text
- [x] Keeps letters capital until you press it again
- [ ] Prints the page
- [ ] Opens a file
> Caps Lock toggles capital letters on and off.

## What does Ctrl + C do?
- [x] Copies the selected item
- [ ] Cuts the selected item
- [ ] Pastes the item
- [ ] Closes the window
> C is for Copy.

## What does Ctrl + V do?
- [ ] Copies
- [x] Pastes
- [ ] Saves
- [ ] Prints
> V pastes what you copied.

## What does Ctrl + Z do?
- [ ] Zooms in
- [x] Undoes your last action
- [ ] Saves your work
- [ ] Selects everything
> Ctrl + Z is Undo.

## What does Ctrl + S do?
- [ ] Shuts down
- [ ] Selects all
- [x] Saves your work
- [ ] Searches the web
> Save often with Ctrl + S.

## What does Ctrl + A do?
- [x] Selects everything
- [ ] Adds a new page
- [ ] Opens a file
- [ ] Underlines text
> A is for All.

## Which keys have small bumps to help you find the home row?
- [ ] A and S
- [x] F and J
- [ ] Q and P
- [ ] Z and M
> The bumps on F and J guide your index fingers.

## WPM stands for:
- [ ] Words per mouse
- [ ] Wires per machine
- [x] Words per minute
- [ ] Windows per monitor
> WPM measures typing speed.

## Which is good typing posture?
- [ ] Slouching low in the chair
- [x] Sitting straight with feet flat on the floor
- [ ] Bending your wrists up sharply
- [ ] Looking only at your hands
> Good posture protects your hands and back.
