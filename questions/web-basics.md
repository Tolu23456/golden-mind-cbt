# Web Checkpoint

## Which language gives a page its structure?

- [x] HTML
- [ ] CSS
- [ ] JavaScript
- [ ] SQL

> HTML labels the content: headings, paragraphs, links and images.

## Which CSS property adds space inside an element's border?

- [ ] `margin`
- [x] `padding`
- [ ] `gap`
- [ ] `border-width`

> Padding is inside; margin is outside.

## Which tag is the best choice for the main navigation?

- [ ] `<div class="nav">`
- [x] `<nav>`
- [ ] `<menu-bar>`
- [ ] `<header-links>`

> Semantic tags such as `nav`, `main` and `footer` describe the page for browsers and screen readers.

## In a stylesheet, how do you target an id called `title`?

- [ ] `.title`
- [x] `#title`
- [ ] `title`
- [ ] `@title`

> A hash targets an id. A dot targets a class.

## What does the DOM represent?

- [ ] The server's hard drive
- [x] The page as a tree of objects JavaScript can change
- [ ] The CSS file
- [ ] The browser history

> The browser builds the DOM from your HTML, and JavaScript edits it.

## Which link points to a file in the same folder?

- [ ] `https://example.com/about.html`
- [x] `about.html`
- [ ] `/about.html`
- [ ] `#about.html`

> A relative link with no domain or leading slash points beside the current page.

## What does `event.preventDefault()` do in a form handler?

- [ ] Deletes the form
- [x] Stops the browser's default action, such as reloading the page
- [ ] Submits the form twice
- [ ] Clears the console

> It lets JavaScript handle the submission without a page reload.

## Which meta tag makes a page work on phones?

- [ ] `<meta charset="UTF-8">`
- [x] `<meta name="viewport" content="width=device-width, initial-scale=1">`
- [ ] `<meta name="phone">`
- [ ] `<meta name="mobile" content="on">`

> The viewport tag tells the phone to use its real width.

## Which is a good reason to put CSS in an external file?

- [ ] It makes HTML invalid
- [x] One file can style every page and the browser can cache it
- [ ] It stops JavaScript running
- [ ] It makes images load faster

> External CSS keeps structure and style separate and avoids repeating rules.

## What is the best first step when a page shows "Cannot read properties of null"?

- [ ] Delete the CSS
- [ ] Add more colours
- [x] Check that the selector matches an element that exists before the script runs
- [ ] Rename the file to .exe

> `null` usually means the element was not found, often because the script ran too early.
