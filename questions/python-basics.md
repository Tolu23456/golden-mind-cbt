# Python Basics

## Which function displays a value on the screen?

- [ ] `echo()`
- [ ] `console.log()`
- [x] `print()`
- [ ] `show()`

> `print("Hello")` writes text to the output.

## Which line creates a list?

- [ ] `numbers = (1, 2, 3)`
- [x] `numbers = [1, 2, 3]`
- [ ] `numbers = {1, 2, 3}`
- [ ] `numbers = <1, 2, 3>`

> Square brackets create a list. Parentheses create a tuple and curly braces a set or dictionary.

## Which keyword defines a function?

- [ ] `function`
- [ ] `fun`
- [x] `def`
- [ ] `define`

> `def greet(name):` starts a function definition in Python.

## Which `if` line has correct Python syntax?

- [ ] `if score >= 50 {`
- [ ] `if (score >= 50) then`
- [x] `if score >= 50:`
- [ ] `if score >= 50 do`

> Python uses a colon and then an indented block. No braces are needed.

## What does `len("Python")` return?

- [ ] 5
- [x] 6
- [ ] 7
- [ ] An error

> `len` counts characters. Python has six letters.

## Which value has the type `bool`?

- [ ] `"True"`
- [ ] `1`
- [x] `True`
- [ ] `None`

> Booleans are `True` and `False`, with capital letters and no quotes.

## Which is the safest way to open a file?

- [ ] `file = open("notes.txt")`
- [x] `with open("notes.txt") as file:`
- [ ] `file.get("notes.txt")`
- [ ] `open.file("notes.txt")`

> `with` closes the file automatically, even if an error happens.

## What does `range(3)` produce?

- [ ] `1, 2, 3`
- [x] `0, 1, 2`
- [ ] `0, 1, 2, 3`
- [ ] `3`

> `range` starts at 0 and stops before the number you give it.
