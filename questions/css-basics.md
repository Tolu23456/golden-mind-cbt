# CSS Basics

## What is CSS mainly used for?

- [ ] Storing data on a server
- [x] Styling how a page looks
- [ ] Adding behaviour to buttons
- [ ] Sending email

> CSS controls colour, text, spacing and layout. HTML gives structure and JavaScript adds behaviour.

## Which selector targets `class="card"`?

- [ ] `#card`
- [x] `.card`
- [ ] `card`
- [ ] `*card`

> A dot means class. A hash means id, and a bare name targets an element.

## Which property changes the colour of text?

- [ ] `background`
- [ ] `font-style`
- [x] `color`
- [ ] `text-color`

> `color` sets the text colour. `background` sets what is behind it.

## Which unit is relative to the root font size?

- [ ] `px`
- [ ] `cm`
- [x] `rem`
- [ ] `pt`

> `rem` scales with the root font size, which helps with accessibility and responsive design.

## Which declaration makes a flex container?

- [ ] `flex: row`
- [ ] `layout: flex`
- [x] `display: flex`
- [ ] `position: flex`

> `display: flex` turns the element into a flex container for its children.

## What does `margin` control?

- [ ] Space inside the border
- [x] Space outside the border
- [ ] The border thickness
- [ ] The text colour

> Padding is inside the border, margin is outside it.

## Which is a valid hex colour?

- [ ] `255, 0, 0`
- [ ] `rgb-red`
- [x] `#f5b93b`
- [ ] `hex(245)`

> Hex colours start with `#` followed by six characters.

## Which media query targets screens 600px wide or narrower?

- [ ] `@media (min-width: 600px)`
- [x] `@media (max-width: 600px)`
- [ ] `@media (width = 600px)`
- [ ] `@media (screen: 600px)`

> `max-width` means "up to and including this width", which is how you target phones.
