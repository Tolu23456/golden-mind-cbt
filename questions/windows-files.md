# Files & Folders

## What is a file?
- [ ] A drawer in the desk
- [x] A piece of work saved on the computer
- [ ] A kind of mouse
- [ ] A type of virus
> A file might be a letter, picture or song.

## What is a folder used for?
- [ ] Printing
- [x] Keeping files together
- [ ] Typing faster
- [ ] Making the screen bright
> Folders organise files.

## Which extension shows a Word document?
- [ ] .mp3
- [x] .docx
- [ ] .xlsx
- [ ] .jpg
> .docx is a Word file.

## Which extension shows an Excel spreadsheet?
- [ ] .docx
- [ ] .pptx
- [x] .xlsx
- [ ] .png
> .xlsx is for spreadsheets.

## Which extension is a picture?
- [x] .jpg
- [ ] .docx
- [ ] .xlsx
- [ ] .mp3
> .jpg and .png are pictures.

## Which is a good file name?
- [ ] new1
- [ ] asdf
- [x] English Homework Week 3
- [ ] untitled untitled
> Clear names help you find your work later.

## What does Ctrl + S do?
- [x] Saves the file
- [ ] Shuts the computer
- [ ] Deletes the file
- [ ] Opens the file
> Save often.

## Where does a deleted file usually go first?
- [ ] The monitor
- [x] The Recycle Bin
- [ ] The keyboard
- [ ] The internet
> You can restore it from the Recycle Bin.

## How do you rename a file?
- [ ] Press Shut down
- [x] Right-click it and choose Rename
- [ ] Drag it to the screen
- [ ] Press Caps Lock
> Right-click and choose Rename.

## Which shortcut copies a file?
- [ ] Ctrl + P
- [x] Ctrl + C
- [ ] Ctrl + Q
- [ ] Ctrl + N
> Copy, then paste with Ctrl + V.

## Which of these cannot be used in a file name?
- [ ] A number
- [ ] A space
- [x] A question mark ?
- [ ] A letter
> Characters like ? / \ : * are not allowed.

## What is a USB flash drive used for?
- [ ] Printing
- [x] Carrying files from place to place
