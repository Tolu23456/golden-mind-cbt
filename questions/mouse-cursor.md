# Mouse & Cursor

## What is the small arrow on the screen called?
- [ ] Menu
- [x] Pointer (cursor)
- [ ] Icon
- [ ] Window
> The pointer moves when you move the mouse.

## Which mouse button do you normally use to select something?
- [x] Left button
- [ ] Right button
- [ ] The wheel only
- [ ] None
> A single left click selects.

## What does a double-click usually do?
- [ ] Deletes the item
- [x] Opens a file or folder
- [ ] Shuts down the computer
- [ ] Prints the item
> Double-click opens things.

## What happens when you right-click?
- [ ] The computer switches off
- [ ] Nothing happens
- [x] A menu of choices appears
- [ ] The page is deleted
> The right button opens a context menu.

## What does drag and drop mean?
- [ ] Throwing the mouse
- [x] Holding the button, moving an item, then releasing
- [ ] Clicking three times
- [ ] Pressing Enter
> Hold, move, release.

## What is the mouse wheel mainly used for?
- [ ] Typing
- [x] Scrolling up and down
- [ ] Printing
- [ ] Turning the screen
> Roll the wheel to scroll.

## What shape does the cursor take over text you can edit?
- [ ] Hand
- [ ] Hourglass
- [x] I-beam
- [ ] Cross
> The I-beam shows where you can click and type.

## A spinning circle beside the cursor means:
- [ ] The mouse is broken
- [x] The computer is busy, so wait
- [ ] You have won
- [ ] The internet is fast
> Wait until it finishes.

## How do you select a whole word?
- [ ] Right-click it
- [x] Double-click it
- [ ] Press Esc
- [ ] Hold Shift only
> Double-click selects a word.

## How do you select a whole paragraph quickly?
- [ ] Click once
- [ ] Double-click
- [x] Triple-click
- [ ] Right-click
> Three fast clicks select the paragraph.

## On a touchpad, which tap usually works as a right-click?
- [ ] One-finger tap
- [x] Two-finger tap
- [ ] Four-finger tap
- [ ] Holding the lid
> Two fingers usually means right-click.

## What should you do if the mouse reaches the edge of the mat?
- [x] Lift it, move it back and continue
- [ ] Throw it away
- [ ] Press harder
- [ ] Switch off the computer
> Lifting does not move the pointer.
