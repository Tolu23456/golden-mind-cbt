# Word Processing

## What is a word processor used for?
- [ ] Playing games
- [x] Typing and formatting documents
- [ ] Calculating budgets only
- [ ] Browsing websites
> Microsoft Word is a word processor.

## Which shortcut makes selected text bold?
- [x] Ctrl + B
- [ ] Ctrl + I
- [ ] Ctrl + U
- [ ] Ctrl + P
> B is for Bold.

## Which shortcut makes text italic?
- [ ] Ctrl + B
- [x] Ctrl + I
- [ ] Ctrl + U
- [ ] Ctrl + S
> I is for Italic.

## Which shortcut underlines text?
- [ ] Ctrl + B
- [ ] Ctrl + I
- [x] Ctrl + U
- [ ] Ctrl + Z
> U is for Underline.

## What must you do to text before you can format it?
- [ ] Delete it
- [x] Select it
- [ ] Print it
- [ ] Save it twice
> Select first, then format.

## What does the blinking line in a document show?
- [ ] A mistake
- [x] Where your typing will appear
- [ ] The page number
- [ ] The file size
> That is the text cursor.

## Which button undoes a mistake?
- [ ] Redo
- [x] Undo
- [ ] Print
- [ ] Paste
> Ctrl + Z also undoes.

## What is a font?
- [ ] A kind of printer
- [x] The style of the letters
- [ ] A saved file
- [ ] A shortcut key
> Arial and Times New Roman are fonts.

## Which alignment puts text in the middle of the page?
- [ ] Left
- [ ] Right
- [x] Center
- [ ] Justify
> Center alignment is often used for titles.

## What does Cut do?
- [ ] Copies the text and leaves it in place
- [x] Removes the text and keeps it ready to paste
- [ ] Saves the document
- [ ] Prints the document
> Ctrl + X cuts.

## What does Paste do?
- [x] Puts copied or cut text into the document
- [ ] Deletes a file
- [ ] Closes Word
- [ ] Changes the font
> Ctrl + V pastes.

## Which shortcut prints a document?
- [ ] Ctrl + S
- [x] Ctrl + P
- [ ] Ctrl + O
- [ ] Ctrl + N
> P is for Print.
