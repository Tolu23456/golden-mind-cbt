# Digital Life Checkpoint

## Which permission should you give to someone who only needs to read a document?

- [ ] Editor
- [x] Viewer
- [ ] Owner
- [ ] Admin

> Share the lowest permission that does the job.

## Which file format is best for a logo that must stay sharp at any size?

- [ ] JPG
- [ ] GIF
- [x] SVG
- [ ] MP3

> SVG is made of shapes and scales without losing quality.

## What is two-step verification?

- [ ] Two passwords on one account
- [x] A second proof of identity after the password
- [ ] Two email addresses
- [ ] Two antivirus programs

> It protects you even when a password is stolen.

## Which is a sign of a phishing message?

- [ ] A calm message you expected
- [x] Urgent language and a request for your password
- [ ] A clear subject line
- [ ] A receipt inside the official app

> Slow down when a message tries to panic you into clicking.

## What should you check before sending money?

- [ ] Only the receiver's photo
- [x] Account number, bank, name and amount
- [ ] The weather
- [ ] Your phone battery

> A transfer is hard to undo. Check every detail.

## What is a hallucination in AI?

- [ ] A slow response
- [x] A confident but invented answer
- [ ] A broken screen
- [ ] A password error

> Verify important facts with a reliable source.

## Which sentence is best for an email to a teacher?

- [ ] "send it now"
- [x] "Dear Mr Bello, please could you send my test score when you have time?"
- [ ] "HELLO"
- [ ] "?????"

> Clear, polite messages get better answers.

## What should you do with a photo that shows a bank card in the background?

- [ ] Post it quickly
- [x] Crop or retake it before sharing
- [ ] Share it only with strangers
- [ ] Add more filters

> Remove private details before sharing any image.

## Which is a good backup habit?

- [ ] Keep one copy on one device
- [x] Keep two copies in two places and check that syncing finished
- [ ] Never save anything
- [ ] Email files to yourself once a year

> One copy is a single point of failure.

## What is the best reason to mute yourself on a video call?

- [ ] To hide your face
- [x] To stop background noise reaching everyone
- [ ] To leave the meeting
- [ ] To save battery

> Mute when not speaking, and unmute before you talk.
