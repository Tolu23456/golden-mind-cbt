# JavaScript Basics

## Which keyword declares a value that cannot be reassigned?

- [ ] `let`
- [ ] `var`
- [x] `const`
- [ ] `fixed`

> `const` prevents reassignment. Use `let` when the value must change.

## Which operator compares value and type?

- [ ] `=`
- [ ] `==`
- [x] `===`
- [ ] `=>`

> `===` is strict equality. `==` converts types first and causes surprises.

## Which statement prints a value to the browser console?

- [ ] `print(value)`
- [x] `console.log(value)`
- [ ] `echo(value)`
- [ ] `document.print(value)`

> Open DevTools with F12 and choose Console to see the output.

## What does a function return if it has no `return` statement?

- [ ] `0`
- [ ] `false`
- [x] `undefined`
- [ ] An error

> A function without a return value gives back `undefined`.

## Which line selects the first element with `class="card"`?

- [ ] `document.getElementById("card")`
- [x] `document.querySelector(".card")`
- [ ] `document.querySelector("#card")`
- [ ] `document.getElementsByTag("card")`

> `querySelector` takes a CSS selector. A dot means class.

## Which event fires when a button is pressed?

- [ ] `"press"`
- [ ] `"tap"`
- [x] `"click"`
- [ ] `"submit"`

> Use `button.addEventListener("click", handler)`. `submit` is for forms.

## Which character starts a template literal?

- [ ] A single quote
- [ ] A double quote
- [x] A backtick
- [ ] A hash

> Backticks let you insert values with `${value}`.

## What is `10 % 3`?

- [ ] 3.33
- [ ] 3
- [x] 1
- [ ] 0

> `%` gives the remainder. 10 divided by 3 leaves 1.
