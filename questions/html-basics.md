# HTML Basics

## What does HTML stand for?

- [ ] Home Tool Markup Language
- [x] HyperText Markup Language
- [ ] High Transfer Machine Language
- [ ] Hyperlink Text Making Language

> HTML is the markup language that gives a page its structure.

## Which tag creates the largest heading?

- [ ] `<head>`
- [ ] `<h6>`
- [x] `<h1>`
- [ ] `<title>`

> Use one `h1` per page for the main title, then `h2`, `h3` and so on in order.

## Which tag wraps a paragraph of text?

- [ ] `<para>`
- [ ] `<text>`
- [x] `<p>`
- [ ] `<pg>`

> `<p>` is a paragraph. It starts on a new line and has space above and below.

## Which attribute describes an image for screen readers?

- [ ] `title`
- [ ] `src`
- [ ] `href`
- [x] `alt`

> The `alt` attribute is read aloud when the image cannot be seen.

## Which tag creates a link?

- [ ] `<link>`
- [x] `<a>`
- [ ] `<href>`
- [ ] `<url>`

> `<a href="page.html">text</a>` makes a clickable link. `link` is for connecting a stylesheet.

## Where does the visible content of a page go?

- [ ] Inside `<head>`
- [ ] Inside `<title>`
- [x] Inside `<body>`
- [ ] Inside `<!DOCTYPE html>`

> `<head>` holds information about the page. `<body>` holds what the visitor sees.

## Which tag makes an unordered list?

- [ ] `<ol>`
- [ ] `<li>`
- [x] `<ul>`
- [ ] `<list>`

> `<ul>` is unordered (bullets), `<ol>` is ordered (numbers), and `<li>` is each item.

## Which line is correctly closed?

- [ ] `<p>Hello<p>`
- [ ] `<p>Hello</P>`
- [x] `<p>Hello</p>`
- [ ] `<p>Hello</ p>`

> Closing tags are lowercase and have no space before the slash.
