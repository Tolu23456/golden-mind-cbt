# Files and folders

## What is a file?

A **file** is one piece of work saved on the computer: a letter, a picture, a song or a video.

## What is a folder?

A **folder** is a container that keeps files together, like a real folder on a desk. A folder can hold other folders too.

## Good habits

1. Give every file a **clear name**, like `English Homework Week 3`, not `new1`.
2. Keep files for one subject in the same folder.
3. **Save often** with [kbd:Ctrl] + [kbd:S] so you do not lose your work.
4. Do not use these characters in a name: `/ \ : * ? " < > |`.

## File types

The last part of a file name, after the dot, tells you the type.

- `.docx` — a Word document
- `.xlsx` — an Excel spreadsheet
- `.pptx` — a PowerPoint presentation
- `.pdf` — a document that is easy to share and print
- `.jpg` or `.png` — pictures
- `.mp3` — music or sound

## Common actions

- **Create** a folder: right-click an empty space, then choose New, then Folder.
- **Rename**: right-click the file and choose Rename.
- **Copy** and **Paste**: [kbd:Ctrl] + [kbd:C] then [kbd:Ctrl] + [kbd:V].
- **Delete**: select the file and press [kbd:Delete]. It goes to the **Recycle Bin**, where you can still get it back.
