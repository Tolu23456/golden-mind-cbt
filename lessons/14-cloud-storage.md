# Saving work in the cloud

The **cloud** is just someone else's computer, reached through the internet. Cloud storage lets you save a file once and open it on your phone, a school laptop or a friend's computer.

## Why use it?

- Your work survives if your own device is lost, stolen or broken.
- You can start on one device and finish on another.
- Several people can work on the same document.
- You can share a link instead of sending a large attachment.

## The main services

- **Google Drive** with Google Docs, Sheets and Slides.
- **Microsoft OneDrive** with Word, Excel and PowerPoint.
- **Dropbox** for simple file storage.
- **iCloud Drive** on Apple devices.

They all do the same core job. Pick one and learn it well.

## Upload, sync and backup

**Uploading** copies a file from your device to the cloud. **Downloading** copies it back down.

**Syncing** keeps a folder the same in both places. If you edit a file on your phone while online, the copy on your laptop updates too. If you edit while offline, the changes merge or conflict when you reconnect.

A **backup** is a copy kept so you can restore an older version. Cloud storage is not a true backup on its own: if you delete a file, the deletion also syncs. Many services keep a **trash** or version history for 30 days, but you should still keep a second copy of important work.

> The golden rule: at least two copies, in two places. One on your device, one in the cloud.

## Sharing safely

A shared file can have different permissions:

- **Viewer** — can read but not change.
- **Commenter** — can leave notes.
- **Editor** — can change or delete.

Share with the smallest number of people and the lowest permission that works. Turn off "anyone with the link" when the file is private. Check the share list after class projects; remove people who no longer need access.

## File sizes and quotas

Free accounts usually give about 15 GB. Photos and videos fill that quickly. If you run out, delete old large files from the trash as well. Emptying the trash is what actually frees the space.

## Working offline

Most cloud apps let you mark files for **offline use**. Do this before a journey or a power cut. When you reconnect, wait for the sync icon to finish before closing the laptop.

## Good habits

1. Use clear folder names: `School/2026/Computer`.
2. Put dates at the start of filenames: `2026-03-14-CV.pdf`.
3. Do not keep five copies called "final", "final2" and "final-real".
4. Check the cloud icon before you close the lid.
5. Log out on shared computers.

## Try it

Create a folder called `Computer Practice`. Upload one document and one photo. Share the folder with a classmate as a viewer, then change them to editor and back again. Finally, check where the trash is.
